# Changelog

Release notes are generated by GitHub for each tag. This file lists what is worth knowing when upgrading.

## Unreleased

- Home: a new landing page that says what to do now (cook what is planned today, use up what expires with a recipe for it, throw away what is past its use-by date, put away checked shopping, plan the open slots, restock), a getting-started checklist for a new household, and this month against the budget. On phones the budget moves from the tab bar to the home page and the account. The same answer is available to assistants as `get_next_actions` (and `GET /api/next-actions`).

- Account: change password, list and sign out devices, delete account, remove household members, personal tokens with an expiry date.
- Security: Bearer tokens can no longer manage the account; sign-up no longer reveals whether an email exists; login limits per IP and per email; `Cache-Control: no-store` on the API; the service worker never keeps API data and is emptied on sign-out.
- Operations: structured logs (`LOG_LEVEL`, `LOG_FORMAT`), configuration validated at startup with every problem listed, graceful shutdown, container health check.
- Behaviour: reading the stock no longer deletes empty items (cleanup happens on write and at startup).
- CI/CD: lint, audit, CodeQL, Trivy, SBOM, provenance and cosign signature, release script.
- Getting started: an empty stock page offers to tick what is at home aisle by aisle (no quantity to type), and an empty recipe book offers 16 simple starter recipes in English and French, imported in one tap without duplicates (`GET /api/starter`, `POST /api/starter/stock`, `POST /api/starter/recipes`).
- Optional local AI: `LLM_BASE_URL` (and `LLM_API_KEY`, `LLM_MODEL`, `LLM_VISION_MODEL`, `LLM_VISION`, `LLM_TIMEOUT_MS`, `LLM_MAX_CONCURRENT`) connect any OpenAI-compatible server (Ollama, LM Studio, llama.cpp). `GET /api/ai/status`, `GET /api/ai/models`, `PUT /api/ai/model` (owner only) and `POST /api/ai/test` are for browser sessions only; the household owner picks the models in Account. Nothing uses the model yet: this is the groundwork for the guided flows.
- Planning: "Plan my week" proposes a menu from what is in stock, what expires and your tastes (no AI needed); you keep, swap or pick each meal before anything is added to the plan. Migration `0017` adds the `proposals` table.
