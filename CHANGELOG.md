# Changelog

Release notes are generated by GitHub for each tag. This file lists what is worth knowing when upgrading.

## Unreleased

- Account: change password, list and sign out devices, delete account, remove household members, personal tokens with an expiry date.
- Security: Bearer tokens can no longer manage the account; sign-up no longer reveals whether an email exists; login limits per IP and per email; `Cache-Control: no-store` on the API; the service worker never keeps API data and is emptied on sign-out.
- Operations: structured logs (`LOG_LEVEL`, `LOG_FORMAT`), configuration validated at startup with every problem listed, graceful shutdown, container health check.
- Behaviour: reading the stock no longer deletes empty items (cleanup happens on write and at startup).
- CI/CD: lint, audit, CodeQL, Trivy, SBOM, provenance and cosign signature, release script.
