Tout ce qu’il faut à une cuisine

Utilisez-la à la main, ou laissez votre IA le faire : chaque action de l’application est aussi un outil qu’elle peut appeler.

📅

La semaine planifiée en quelques minutes

Posez une recette ou une simple note sur chaque jour. Les créneaux vides ressortent : plus de « on verra ».

🛒

Des courses qui se préparent seules

Un clic transforme les repas de la semaine en liste : ce qu’il faut, moins ce qu’il y a déjà. Triez par rayon et cochez en faisant les courses.

🧊

Savoir ce qu’il y a dans le frigo

Voyez ce qui expire en premier, soyez alerté pour les pots ouverts et cuisinez ce que vous avez avant d’en racheter.

📖

Des recettes adaptées à votre cuisine

Notez et mettez en favori, voyez ce que vous pouvez cuisiner ce soir, et soyez prévenu si une recette demande un appareil que vous n’avez pas.

💶

Un budget courses maîtrisé

Enregistrez vos tickets, fixez un budget mensuel et voyez où vous allez finir avant la fin du mois. Dans la devise de votre choix.

🍎

Calories et macros, seulement si vous voulez

Activez la nutrition pour voir calories, protéines, glucides et lipides de chaque recette. Les valeurs viennent d’Open Food Facts ou de vos chiffres, et l’appli signale l’ingrédient manquant. Désactivé par défaut.

🥕

Manger de saison

Un calendrier des fruits et légumes de votre pays. Les articles hors saison de la liste viennent avec des alternatives de saison.

🥗

Régimes et allergies pris en compte

Végétarien, sans gluten, les 14 allergènes de l’UE, ce que quelqu’un n’aime pas : les recettes qui ne conviennent pas sont signalées et jamais suggérées.

♻️

Moins de gaspillage, moins de répétitions

Retient ce que vous avez cuisiné pour varier les menus, et chiffre ce que coûte vraiment la nourriture jetée.

👨‍👩‍👧

Un foyer, tout le monde synchronisé

Invitez la famille. Les changements apparaissent aussitôt sur chaque appareil, y compris ceux de votre IA.

MCP

Pensé pour les assistants IA

La même logique métier alimente l’interface web et un point d’accès MCP. Connectez Claude (ou tout client MCP) et parlez-lui : il lit votre stock, planifie la semaine, construit la liste et enregistre le ticket de caisse.

  • OAuth 2.1 intégré : découverte, enregistrement dynamique des clients, PKCE. Collez l’adresse, connectez-vous, autorisez. Révocable à tout moment.
  • Jetons personnels pour les scripts et clients sans OAuth. Le même jeton ouvre l’API REST.
  • Plus de 40 outils : stock, recettes, planning, courses, budget, équipement, variantes en lot.
  • Cloisonné par foyer : chaque requête n’agit que sur le foyer de la personne connectée.

Dans votre poche

La même application sur téléphone : barre d’onglets en bas, utilisable d’une main, installable sur l’écran d’accueil.

Installez-le en deux minutes

Un conteneur, un fichier SQLite. Image multi-architecture (amd64 et arm64) publiée sur le GitHub Container Registry.

Récupérez les fichiers

Prenez docker-compose.yml et .env.example dans le dépôt et copiez l’exemple vers .env. Renseignez PUBLIC_URL avec l’adresse réelle de l’application.

Démarrez

cp .env.example .env   # puis éditez PUBLIC_URL
docker compose up -d

Créez le premier compte

Ouvrez l’application : le premier compte devient propriétaire du foyer. Invitez les autres depuis l’onglet Compte avec un code à usage unique.

Connectez votre IA

Ajoutez PUBLIC_URL/mcp comme serveur MCP dans Claude. Les clients distants exigent HTTPS : placez l’application derrière un reverse proxy.

Les mots de passe sont hachés avec scrypt, les sessions utilisent des cookies HttpOnly/SameSite, les jetons sont stockés hachés et les connexions sont limitées en débit. Vos données restent sur votre serveur.

Sous le capot

Express 5, TypeScript, Drizzle avec SQLite, le SDK MCP officiel et Zod côté serveur ; React 19, Vite et Tailwind 4 côté web. L’API REST et le serveur MCP sont deux fines couches au-dessus des mêmes services : une règle métier s’écrit une seule fois.

server/src
  db/        Drizzle schema + SQLite, migrations at startup
  domain/    Zod schemas, units, dates, errors
  auth/      accounts, sessions, households, OAuth server
  services/  all the business logic (per household)
  api/       REST adapter (web UI)
  mcp/       MCP adapter (AI clients)
web/src      React + Vite + Tailwind UI (EN / FR)
